# Reservation Management System

A RESTful API for managing resource reservations, built with NestJS and MongoDB.

## Tech Stack

- Node.js
- NestJS
- TypeScript
- MongoDB
- Mongoose
- JWT Authentication

## Core Features

- User registration and authentication
- Role-based access control (Admin and Customer)
- Resource management
- Reservation creation and management
- Reservation availability and conflict handling

## Prerequisites

- Node.js
- npm
- MongoDB

## Installation

```bash
git clone https://github.com/zeiadkh/reservation-app.git
cd reservation-app
npm install
```

## Environment Variables

Create a `.env` file in the project root. Required variables will be documented here as the application configuration is implemented.

## Running the Application

```bash
npm run start:dev
```

## Testing

```bash
npm test
npm run test:e2e
npm run test:cov
```
